# Water dimer quickstart

[Download the example XYZ](water-dimer.xyz?raw=1)

The hand-built starting geometry contains six atoms. The initial O···O distance is 2.90 Å.

| Setting | Value |
| --- | --- |
| Task | Single-point energy |
| Method and basis | HF/STO-3G |
| Solvent | Gas phase |
| Total charge | 0 |
| Spin multiplicity | 1 |

1. Import the XYZ through the File menu and select the two oxygen atoms to confirm their separation.
2. Apply the calculation settings above and select a configured PySCF server.
3. Submit the job and follow it in the job monitor. When it completes, open its entry in the project library to check SCF convergence and the final electronic energy.
